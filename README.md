# Cairo-My-Solo-Project
Visit Cairo – Responsive Webpage  This project is a responsive webpage built with HTML and CSS that showcases Cairo, Egypt as a travel destination.
Features
Hero Section: A full‑width background image with title and subtitle introducing Cairo.

Activities Section: Three interactive cards highlighting top things to do in Cairo, with hover effects on circular images.

Guide Section: A styled card presenting a local tourist guide, including image, description, and list of services.

Responsive Design: Layout adapts to different screen sizes using flexbox and media queries, ensuring readability on desktop, tablet, and mobile.

Custom Fonts: Integrated Google Fonts and a local font (Safaniah.ttf) for unique typography.

Consistent Styling: Gradient background, dotted borders, rounded corners, and hover transitions for a polished look.

Purpose
The webpage demonstrates responsive design principles and creative styling for a travel‑themed landing page. It can serve as a portfolio project, a template for tourism websites, or a learning exercise in modern CSS techniques.
